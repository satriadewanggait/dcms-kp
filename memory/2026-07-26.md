# dcms-kp — 26 Jul 2026

## Role & Approval System Implementation

### What was added:
1. **Prisma Schema** — Added `role` (default: "user") & `status` (default: "pending") to User model
2. **Migration** — `add_role_status` berhasil dijalankan
3. **Webhook** — Semua user baru otomatis `status: "pending"` dan `role: "user"`
4. **API Routes:**
   - `GET /api/user/status` — Cek status & role user
   - `GET/POST /api/admin/users` — List users, approve/reject/change role (admin only)
5. **Pages:**
   - `/pending-approval` — Halaman buat user yang belum di-approve
   - `/rejected` — Halaman buat user yang ditolak
   - `/admin/users` — Admin panel untuk manage users
6. **Navbar** — Menu "Manage" muncul otomatis kalo user role = admin
7. **AuthGate** — Otomatis redirect pending/rejected users dari halaman protected

### Flow:
- Register → Clerk webhook → status "pending" → redirect ke /pending-approval
- Admin login → Sidebar Manage → Approve user + set role
- User next login → status "active" → masuk dashboard
